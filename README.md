# Legado — Primeiros 7 dias

PWA brasileiro para organizar providências práticas após um falecimento: primeiras horas, funerária, velório, despedida e primeiros sete dias.

- Sem banco de dados, cadastro, rastreamento ou backend.
- Salva tarefas, responsáveis e anotações **apenas no dispositivo**, usando localStorage.
- Instalável pelo navegador no Android após a publicação via GitHub Pages.
- Funciona offline após o primeiro carregamento e armazenamento do app.
- Permite exportar e importar um backup JSON local.

Este aplicativo não substitui orientações de hospitais, cartórios, funerárias ou autoridades locais. Não trata inventário, herança ou finanças.
